How to Play?
1. Use cd store to open the store and buy flower seeds.
2. Use cd inventory to check your seeds.
3. Click an empty farm plot and plant a seed.
4. Click Next Day to grow flowers.
5. Sometimes a flower gets a bug...
6. Fix the buggy code so the flower can keep growing!
7. Harvest flowers when they are ready!
8. Harvest more flowers to unlock new flower types!~
Commands
cd farm - go back to your farm
cd farm/inventory - open your inventory
cd store - open store
cd farm/stats - open statistics page
cd help - open help page
